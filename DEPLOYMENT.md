# Deployment

The canonical production deployment is:

https://echoes-of-alderwood.vercel.app

The production domain currently responds publicly. Vercel preview deployments may still be protected by Vercel Authentication. Before sharing a preview build with external play-testers, the project owner must either disable Deployment Protection for that environment in the Vercel project settings or share the public production domain above.

No deployment-security setting is changed by the game code.
